# Sasanka Akash Portfolio

A personal portfolio website for Sasanka Akash, built with React and Vite. The site includes an animated hero section, light and dark themes, selected work, writing links, social profiles, and a responsive layout.

## Tech Stack

- React 18
- Vite
- lucide-react
- CSS with responsive media queries

## Getting Started

### Prerequisites

- Node.js 18 or newer
- npm

### Installation

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

Vite will print the local URL in the terminal, usually `http://localhost:5173`.

### Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Project Structure

```text
.
├── public/          # Static assets
├── src/
│   ├── main.jsx     # React application and page content
│   └── styles.css   # Global styles and responsive layout
├── index.html       # HTML entry point
├── package.json     # Dependencies and scripts
└── README.md
```

## Customization

Update the content arrays and JSX in `src/main.jsx` to change the hero copy, projects, writing links, and contact details. Adjust the design tokens and responsive rules in `src/styles.css` to change the visual style.
